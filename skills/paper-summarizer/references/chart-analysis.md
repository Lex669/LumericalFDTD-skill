# 图表详解方法论

图表分析不只是视觉描述——目标是让没看过论文的人读完图表解释后能完全理解论文的数据支撑体系。

## 按图表类型的分析重点

### 数据类图表（线图、散点图、柱状图、热力图等）

数据类图表是论文最核心的论据支撑，不能只描述"X随Y增加而上升"，要解释量的关系。

- **坐标轴**：含义和单位（X轴是什么，Y轴是什么），对数还是线性
- **数据序列**：每条曲线/每组柱子代表什么条件或方法，用论文中的术语
- **数据趋势**：上升/下降/饱和/U型/单调/振荡，趋势变化发生在什么区间内
- **数值范围**：最大值、最小值、转折点的具体数值
- **对比关系**：谁比谁好、好多少、在什么条件下；绝对差值 vs 百分比
- **误差与不确定性**：误差棒/置信区间反映了什么（测量误差？样本方差？），各组误差范围是否有重叠

### 图像类图表（显微照片、SEM、TEM、AFM、光学照片等）

图像类图表是材料/器件论文的核心实证证据，需要识别图像中的物理结构。

- **标尺与放大**：放大倍率、标尺长度，据此推算特征尺寸
- **结构识别**：图像中的关键结构、不同区域/相/缺陷的识别，用箭头或区域标注辅助说明
- **子图对比**：不同条件、不同样本、不同放大倍率下的对比，差异是否显著
- **图像质量**：清晰度、噪声水平、对比度、是否存在处理过度（过度锐化/对比度拉伸）的痕迹

### 流程图与示意图

流程/示意图是理解方法的关键，可以解释"怎么做"。

- **流程走向**：起点和终点，各步骤的先后顺序
- **模块功能**：每个模块/步骤做什么，输入什么、输出什么
- **信息流向**：数据/信号的流向和变换
- **图文对账**：图中的步骤是否在文中方法部分有对应描述，图是否比文字更清晰或更模糊

### 表格

表格通常汇总最重要的对比或参数，是快速判断方法优劣的窗口。

- **最优值标注**：原文加粗/加下划线的数据往往是作者声称的最优结果
- **对比基线**：表格中的对比方法/基线是什么，提升是相对于谁的
- **提升幅度**：绝对值和百分比都要看——有时百分比好看但绝对值很小
- **统计标注**：p值、*/**/*** 的含义，确认统计检验是否规范

## 图表质量评价维度

在"图表质量评价"中从以下维度客观审视：

| 维度 | 关注点 |
|------|--------|
| **清晰度** | 分辨率是否够高？文字/数字是否可读？ |
| **标注完整性** | 坐标轴标签、图例、单位、子图编号是否齐全？ |
| **色觉友好性** | 是否仅靠颜色区分数据序列？红绿色盲能否读懂？ |
| **误差表达** | 误差棒、置信区间、显著性标注是否规范？ |
| **可视化诚实性** | 坐标轴是否从零开始（如适用）？是否存在截断Y轴误导？双Y轴是否合理？ |
| **信息密度** | 图表是否过于空洞或过于拥挤？ |

## 完成后自我检查

逐图表检查以下问题，逐一确认通过后图表分析才算完成：

1. 每个图表的解释中是否包含了"与论文论点的关系"？
2. 论文提到的每个结论是否有对应的图表支撑？（从结论反查图表）
3. 如果论文声称"A优于B"，是从哪个图的哪个数据看出来的？
4. 每个子图都被单独分析了，还是笼统概括了整个 Figure？
5. 是否有图表只被提及但没有真正用于支撑论点（装饰性图表）？
