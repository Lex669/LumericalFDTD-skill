# 本轮资产与视觉约定

来源：现有 `docs/` 源码、README、插件清单及上轮评审。项目事实沿用上轮已核验的 `design-review/product-facts.md`。

- 自有项目标识：继续引用 `docs/assets/mark.svg`，不重新绘制商标。
- 平台名称：按评审中“官方资源或纯文字”的建议采用纯文字 Claude Code / Codex，移除原来的星形和 Command 字形。它们不作为平台官方图标展示。
- Ansys Lumerical：以软件依赖名称出现，保留独立开源项目说明和许可要求，不添加官方背书。
- 无实物产品、无可用真实仿真截图；新增图形是模型截面示意，并附参数缺失和非按比例说明。

## 色彩与排版

- 浅色底 `#f4f1ec`、表面 `#faf8f5`、文字 `#2e2b30`。
- 次级文字 `#68636b`、辅助文字 `#736b76`。
- 强调色 `#79658c`，浅强调底 `#e9e2ed`；在浅强调底上使用更深的次级文字。
- 深色沿用现有 `#1b191d` 与 `#bca7cc` 体系，文字分级分别实测。
- 系统中文无衬线正文，等宽字体仅用于命令、文件和数据标签。
- 正文 16px；辅助说明 12–14px；代码 14px；主按钮与标签等点击区域至少 44px 高。
