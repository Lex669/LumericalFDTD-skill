# 现有网页动效迭代

2026-10-27。用户原话：“目前还缺少动效，对此将其加入”。这是已选定网页方向中的动效补充，适用同项目迭代例外；保留当前版式、字体、配色和内容，不另做三个全新视觉方向，不声称用户明说过跳过流程。

## 动效形式与内容

- 叙事角色：首屏建立注意力，波前呼应光学主题；流程按需求、模型、产物顺序呈现；界面动效解释选中、复制和展开状态。
- 观众距离：手机和笔记本，保持上一轮字号、触控尺寸和对比度。
- 温度：克制、连贯、适合科研工具。用缓慢传播和短促操作反馈，不加入声效、全屏转场或电影式时间轴。
- 容量：一套首屏入场、一个可暂停的波前循环、一套流程衔接，以及操作反馈。正文默认可见。
- 母题：波传播与任务的连续衔接，来自光学仿真内容和实际使用流程。

## 轻量分镜 / 时间安排

| 触发 | 动作 | 时长 |
| --- | --- | --- |
| 首次载入 | 标题、描述、入口依次轻移归位，输入波形描线 | 约 0.6–1.6 秒，单次 |
| 首屏可见 | 信号沿输入曲线传播，波前缓慢扩散 | 6.4 秒周期，可暂停 |
| 任务流程首次进入视口 | 三步依序归位，模型示意轻微构建反馈 | 约 0.7 秒，单次 |
| 标签切换 | 选中背景连续移动，内容短距离归位 | 0.22–0.32 秒 |
| 复制成功、菜单、主题、历史展开 | 对应控件局部反馈 | 0.18–0.32 秒 |

不新增科学结果、品牌图标或外部素材；资产约定沿用 `../iteration/brand-spec.md`。这是网页交互动效，不是视频交付，不添加音轨、水印或长片导演稿。

## 可访问性与降级

- 跟随 prefers-reduced-motion，系统开启时停止 CSS 与 JavaScript 动画。
- 提供用户可见的暂停 / 播放按钮，并保存手动选择。
- 首屏离开视口、页面进入后台时暂停循环；离开后台时不重播正文入场。
- 不使用动画控制 hidden / aria-selected 或焦点逻辑；无 JavaScript 时保留可读的静态页面。
- 不对正文使用透明度入场，避免动效过程降低文字对比度。
